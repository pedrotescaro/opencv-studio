# Avaliação fora do cadastro

`grupo.jpeg` é a foto coletiva fornecida pelo grupo. Ela não entra no treinamento.
Abra em **Rostos e chamada → Abrir foto** para comparar os rostos com a galeria.
O sistema mostra suas previsões; confirme visualmente cada identificação.

Abrir uma foto não registra chamada ao vivo. O ensaio de resistência a uma foto
apresentada à câmera é separado: a implementação não oferece prova de vida.
