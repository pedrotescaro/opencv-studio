# Paulo Henrique Leal dos Santos

Coloque aqui as fotos de cadastro do Paulo: pelo menos duas imagens distintas,
preferencialmente 10 a 20, com somente o rosto dele visível em cada imagem.
Use JPG, JPEG, PNG, BMP, TIFF ou WebP. Reserve outras fotos fora desta pasta
para testar o reconhecimento sem repetir as imagens de treinamento.

Depois, no programa: **Rostos e chamada → Cadastro → Treinar com as fotos do grupo**.
As outras duas pastas também precisam ter fotos. Consulte o [guia do grupo](../README.md).
